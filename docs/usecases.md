# Cas d'usage du système de ticketing

## Use cases principaux
1. **Créer un ticket** : Un utilisateur ouvre une demande.
2. **Assigner un ticket** : Un agent prend en charge un ticket.
3. **Changer la priorité** : Un admin ajuste l'urgence d'un bug.
4. **Ajouter un commentaire** : Un utilisateur ou un agent discute sur le ticket.
5. **Résoudre un ticket** : L'agent marque le travail comme fait.
6. **Clôturer un ticket** : L'utilisateur confirme que le problème est réglé.
7. **Lister mes tickets** : Un utilisateur voit ses demandes en cours.
